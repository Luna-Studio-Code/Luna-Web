# fold-pc

폴더블 폰을 미니 노트북처럼 쓰는 원격 조작 도구입니다. 폰 화면 위쪽 절반에는 PC 화면이, 아래쪽 절반에는 실제로 동작하는 키보드와 트랙패드가 나옵니다. 윈도우 PC 기준으로 만들었고 맥에서도 돌아가게 되어 있습니다.

PC에서 작은 서버를 실행하고, 폰은 앱 설치 없이 브라우저로 접속합니다. 폰과 PC가 같은 와이파이에 있어야 합니다.

## 실행 (윈도우)

1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다. (한 번만)
2. 이 `fold-pc` 폴더의 `start.bat`을 더블클릭합니다. 처음에는 필요한 파일을 자동으로 받습니다.
3. 방화벽 창이 뜨면 **개인 네트워크**에서 허용합니다.
4. 브라우저에 열린 페이지에서 **화면 공유 시작**을 누르고 **전체 화면**을 고릅니다.
5. 검은 창(터미널)에 나온 QR 코드를 폰 카메라로 찍습니다.

터미널에서 직접 실행하려면 `npm install` 후 `npm start`입니다.

## 조작법

| 동작 | 방법 |
| --- | --- |
| 커서 이동 | 트랙패드를 한 손가락으로 문지르기 |
| 클릭 | 트랙패드 톡 치기 |
| 더블클릭 | 두 번 톡톡 |
| 우클릭 | 두 손가락으로 톡 |
| 스크롤 | 두 손가락으로 밀기 |
| 드래그 | 톡 친 직후 다시 대고 움직이기 |
| 화면 직접 클릭 | 위쪽 PC 화면에서 원하는 곳을 톡 |
| 단축키 | ctrl·shift·alt·⊞를 누른 채 다른 키. 한 손이면 보조키를 먼저 톡(주황색 테두리) 치고 다음 키 |
| 한/영 전환 | `한/영` 키 |
| 전체 화면 | 키보드 오른쪽 위 `⛶` 키 |

## 알아둘 점

- 주소에 들어 있는 `t=...` 값이 비밀번호 역할을 합니다. 이 주소를 아는 사람은 같은 와이파이에서 PC를 조작할 수 있으니 공유하지 마세요. 바꾸려면 폴더의 `.token` 파일을 지우고 다시 실행합니다.
- 관리자 권한으로 실행된 창(작업 관리자, 설치 프로그램 등)은 윈도우 보안 정책상 조작되지 않습니다.
- 화면 공유 탭을 닫으면 폰 화면도 멈춥니다. 최소화는 괜찮습니다.
- 맥에서는 `npm start`로 실행하고, 터미널에 "손쉬운 사용" 권한을, 브라우저에 "화면 기록" 권한을 줘야 합니다.

## 구조

- `server.js` — 페이지 제공, 화면 연결 중계, 접속 토큰 확인
- `input.js` — 폰에서 온 입력을 실제 마우스·키보드 동작으로 바꿈
- `public/host.html` — PC 브라우저에서 화면을 캡처해 폰으로 전송 (WebRTC)
- `public/client.html` — 폰에 보이는 화면, 키보드, 트랙패드
